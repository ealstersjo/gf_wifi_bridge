Diagnostics & logs

Understand whether a problem is in the G30, Android gateway or web connection.

Possible errors

Reference for errors currently handled by the gateway.
G30 / BLEBluetooth unavailable

Android Bluetooth is off or permission is missing.

Turn on Bluetooth and grant Nearby devices permission.
G30 / BLEG30 not found

No likely Grainfather was found before scan timeout.

Keep the G30 powered and nearby, then scan again.
G30 / GATTConnection failed

Android could not establish or discover the required GATT services.

Power-cycle the G30 and retry the connection.
G30 / STATEG30 disconnected

A command requires a connected and ready Grainfather.

Connect the G30 before sending a command.
G30 / COMMANDConfirmation timeout

A command was written but the controller did not confirm it.

Check G30 connectivity; the displayed state remains controller-reported.
G30 / COMMANDCommand already pending

A second command was requested before the previous one was confirmed.

Wait for the pending/confirmed/failed status to finish.
G30 / INPUTInvalid target temperature

The submitted target is not a valid finite temperature value.

Enter a numeric value, then apply it again.
ANDROIDGateway internal error

The Android runtime, server, storage or service reported an internal failure.

Check the Android service and inspect the live log details.
ANDROID / APIInvalid request

The gateway rejected a malformed or unsupported API request.

Check the live log for the endpoint and validation detail.
ANDROID / APIOperation failed

A valid operation failed in the gateway or its domain service.

Retry once and inspect the correlated Android log event.
ANDROID / NETWORKmDNS unavailable

The local hostname could not be registered or resolved.

Use the displayed IP address as fallback and check local-network multicast.
ANDROID / SESSIONSession or recipe not found

The requested stored session or recipe no longer exists.

Refresh the list and select an existing item.
WEB / HTTPGateway request timeout

The browser request did not receive a gateway response in time.

Check gateway service status and the current local URL.
WEB / HTTPInvalid gateway response

The browser received a response that was not valid gateway JSON.

Check the gateway build and inspect the HTTP debug event.
WEB / WEBSOCKETWebSocket reconnecting

The browser lost the gateway connection and is retrying.

G30 state does not cause this; check gateway/network availability.
